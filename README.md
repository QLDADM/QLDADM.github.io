# Strony projektu Dron Detector

Publiczne strony projektu **Dron Detector**, publikowane przez GitHub Pages.

| Strona | Adres |
|---|---|
| Podgląd dronów na telefonie i tablecie | **https://qldadm.github.io/dron-detector/** |

Strona łączy się przez Bluetooth z płytkami odbierającymi Remote ID i pokazuje drony w okolicy: odległość i kierunek,
mapę, radar, widok 3D, wysokość (także nad terenem), prędkość, położenie operatora oraz oznaczenia swój/obcy.
Działa w przeglądarce Google Chrome na Androidzie, nie wymaga instalacji ani konta.

To repozytorium zawiera tylko gotowe pliki stron. Są one kopiowane z repozytorium źródłowego projektu.
